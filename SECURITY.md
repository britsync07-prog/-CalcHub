# Security Policy

## Supported Versions

The following versions of **Everyday Calculator Hub** are actively maintained with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

As an open-source project maintained by an individual independent developer, security and mathematical accuracy are top priorities.

If you discover a security vulnerability, data leakage issue, or calculation flaw:

1. **Do not create a public issue.**
2. Send an email with details, reproduction steps, and any proof-of-concept to **Musfiqur Rahman Saimon** at `musfiqursaimon7@gmail.com` (or open a private security advisory on GitHub).
3. You will receive an acknowledgment within 24–48 hours with remediation steps.
4. Once resolved and deployed, appropriate credit will be given in release notes.

Thank you for helping keep open-source software safe and reliable!
